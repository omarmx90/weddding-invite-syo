# Imágenes marcadoras de posición

Coloca aquí la fotografía final y apunta `src/content/wedding.ts` → `media.hero.src` al nuevo archivo.

| Archivo | Rol |
| --- | --- |
| `hero.svg` | Sustituto atmosférico temporal de la portada |

Recomendaciones para la foto real del hero:

- Orientación vertical preferida (recorte mobile-first)
- Exportar WebP o JPEG de alta calidad; Next.js servirá AVIF/WebP cuando sea posible
- Mantener un peso razonable (idealmente bajo ~400 KB antes de subir; Next optimizará)
- Actualizar el texto `alt` en el contenido al reemplazar

No subir fotografías con derechos de autor tomadas de internet.
